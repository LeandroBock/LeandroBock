## 🚀 Proyectos destacados

### 📅 Turnify: plataforma de gestión de turnos y servicios
Aplicación web para gestionar turnos y servicios, con frontend y backend integrados mediante API REST, autenticación de usuarios y pagos online. Proyecto en equipo con metodología Scrum.

- Desarrollo de frontend y backend
- Endpoints y persistencia de datos
- Autenticación y manejo de usuarios con JWT
- Integración de pagos con Stripe

`React` `JavaScript` `NestJS` `TypeScript` `PostgreSQL` `TypeORM` `JWT` `Stripe`

🔗 [Demo](https://turnify-frontend.onrender.com/) · 📂 [Repositorio](https://github.com/Turnify-Proyect/Turnify)

### 🥩 DeFalcis Achuras: sistema de gestión comercial (freelance)
Sistema web para centralizar las operaciones de un comercio de achuras y cortes de carne.

- Interfaz web para la gestión comercial
- Backend con NestJS y TypeScript
- Modelado y persistencia con PostgreSQL y TypeORM
- Administración de productos, clientes, pedidos, inventario y resultados financieros
- 🚧 **En desarrollo:** bot de WhatsApp para toma automática de pedidos y facturación electrónica con ARCA

`React` `JavaScript` `NestJS` `TypeScript` `PostgreSQL` `TypeORM`

🔗 [Demo](https://defalcis-achuras-front.onrender.com/) · 📂 [Frontend](https://github.com/LeandroBock/DeFalcis-Achuras-Front) · 📂 [Backend](https://github.com/LeandroBock/DeFalcis-Achuras-Back)
